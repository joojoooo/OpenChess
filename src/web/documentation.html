🎮 Physical Board Overview

How It Works

OpenChess is a smart chessboard that detects piece movements using hall-effect sensors beneath each square and provides interactive feedback through a WS2812B LED strip. The board connects to WiFi and can play against Stockfish AI or facilitate online games via Lichess.

Hardware Architecture

  • 64 Hall-Effect Sensors: Detect when magnetic pieces are placed on or removed from squares
  • Shift Register Scanning: Efficiently reads all sensors using a column scanning pattern
  • LED Strip (WS2812B): Full RGB lighting with ~9 LEDs per square for animations and move visualization
  • GPIO Inputs: Row pins and column outputs managed by the ESP32
  • Calibration System: Maps physical sensor layout to logical board coordinates

Board Coordinates

Row 0 = Rank 8 (Black's back rank, top of board)

Col 0 = File A (Left side of board)

The board uses standard chess notation: squares are identified as file (a-h) + rank (1-8).

Online Play

To play against a bot, use the Lichess platform or access the OTA firmware update, you have to connect the board to the internet. The following sites need to be accessible:

pool.ntp.org, time.nist.gov, api.github.com, lichess.org, stockfish.online

MODE 1 Chess Moves (Human vs Human)

What It Is

Play a traditional game of chess with another person on the physical board. The board detects all piece movements and validates them against chess rules. No AI opponent—perfect for playing with friends or family.

Features

  • Real-time move detection from piece placement on board
  • LED visualization of valid moves (white LEDs on possible destination squares)
  • Check detection with yellow LED warning on checked king
  • Automatic pawn promotion detection (web UI overlay)
  • Move history tracking and game save/resume
  • Checkmate, stalemate, and draw detection
  • 50-move rule and threefold repetition tracking

How to Play

  1. From the home page, click GameMode Selection
  2. Select Chess Moves
  3. Set up the board with pieces in starting position
  4. Pick up a piece—available move destinations light up in white
  5. Place the piece on your desired square
  6. The board validates the move and updates automatically
  7. For pawn promotions, a web UI overlay lets you choose the piece

Game End

  • Checkmate: Game ends, winner announced
  • Stalemate: Draw declared
  • Resign: Lift both kings to surrender (if supported)
  • Draw Agreement: Can be offered via web interface

MODE 2 Chess Bot (vs Stockfish AI)

What It Is

Play against Stockfish, a powerful open-source chess engine accessible via API. Choose your difficulty level and piece color, and the AI will play as your opponent. Perfect for practice and improving your chess skills.

Features

  • 4 difficulty levels: Easy (5), Medium (8), Hard (11), Expert (15)
  • Play as White or Black
  • Real-time bot move calculation
  • Automatic piece movement visualization (LEDs guide you to opponent's moves)
  • Evaluation display showing position advantage
  • Move history and game replay
  • Full game save and resume capability

How to Play

  1. From the home page, click GameMode Selection
  2. Select Chess Bot
  3. Choose the bots color (White or Black).
  4. Select difficulty level:
    • Easy: Quick and beatable for beginners
    • Medium: Balanced, recommended for most players
    • Hard: Strong opponent, slow calculation
    • Expert: Very challenging, very slow
  5. Click Start Game
  6. Make your move on the board
  7. Wait for the AI to calculate (blue LEDs indicate "thinking")
  8. Bot moves will be shown with LED animations

Game Controls

  • Click View Board to see the current position and evaluation
  • Use web interface to resign or offer a draw
  • Board edit mode allows you to set up specific positions for practice

Performance Notes

  • Expert difficulty may take 30+ seconds per move
  • Requires stable internet connection to Stockfish API
  • WiFi connection is essential

MODE 3 Lichess (Online Play)

What It Is

Play live games against opponents from around the world on Lichess.org, one of the largest online chess communities. Your physical board becomes a real-time interface for online chess.

Features

  • Challenge players worldwide via Lichess
  • Various time controls and game formats
  • Real-time opponent move display on physical board
  • Automatic move detection from piece placement
  • Move countdown timer with LED pulse
  • Full game history with analysis tools
  • Integrates with your Lichess account

Setup Requirements

  1. Create a free account at lichess.org
  2. Generate a personal API token from your Lichess account settings
  3. Enter the token in OpenChess home page settings (Lichess section)
  4. Token is saved securely on the device

How to Play

  1. Ensure Lichess API token is configured
  2. From the home page, click GameMode Selection
  3. Select Lichess
  4. A challenge invitation link is generated
  5. Share the link with your opponent
  6. Once accepted, the game starts
  7. Make moves on the physical board as usual
  8. Opponent's moves appear automatically

Game Flow

  • Board polls Lichess every 500ms for opponent moves
  • When opponent moves, LEDs highlight their move
  • Your time is limited—make moves before the clock expires
  • Game ends on checkmate, time expiration, resignation, or draw

Online Status

  • WiFi connection is required
  • Stable connection ensures smooth gameplay
  • If connection drops, game may be forfeited

MODE 4 Sensor Test (Diagnostic)

What It Is

A diagnostic mode for testing the physical board's sensors and LEDs. Use this to verify that all 64 squares are functioning properly, troubleshoot hardware issues, and calibrate the board if needed.

Features

  • Test all 64 hall-effect sensors individually
  • Verify LED functionality across the strip
  • Check for dead or malfunctioning squares
  • Calibration wizard for mapping sensors to coordinates
  • Real-time feedback on sensor readings
  • GPIO pin configuration display

How to Use

  1. From the home page, click GameMode Selection
  2. Select Sensor Test
  3. The board enters diagnostic mode
  4. Place a magnet on each square to test sensor detection
  5. Watch for LED response and sensor reading confirmation
  6. Note any squares that don't respond

Troubleshooting

  • Sensor doesn't respond: Check magnetic piece is placed directly over sensor
  • LED not lighting: May indicate LED strip issue—check hardware
  • Wrong coordinate: Board calibration may need adjustment

Calibration

If the board's sensor-to-coordinate mapping is incorrect, use the calibration tool:

  1. From the home page, scroll to LEDs & Board
  2. Click Calibrate Board
  3. Follow on-screen instructions to map physical pins to logical squares
  4. Calibration data is saved to device storage

👆 User Gestures & Interactions

Physical Board Gestures

  • Pick Up Piece: Lift a piece from a square—LEDs show all valid destinations
  • Place Piece: Put piece on destination square—move is validated and applied
  • Resign (if supported): Lift both kings simultaneously to forfeit the game
  • Promote Pawn: When a pawn reaches the 8th or 1st rank, a web UI overlay appears to select promotion piece (Queen/Rook/Bishop/Knight). You have 2 minutes to decide.

Web Interface Interactions

Game Selection Page
  • Click Game Mode Card: Select a game mode (modes 1-4)
  • Bot Configuration: When selecting Chess Bot, a panel appears to choose color and difficulty
Board View Page
  • FEN Display: Shows current position in FEN notation
  • Move Navigation: Use first/prev/next/last buttons to review moves
  • Edit Board: Click to enter edit mode for setting up positions
  • Resign / Draw: Buttons to end the game or offer a draw
  • Game History: View list of previous games and load them
Settings Page
  • WiFi Section: Configure WiFi credentials, scan for networks
  • Lichess Section: Enter and manage your Lichess API token
  • LEDs & Board Section: Adjust brightness, dim multiplier, and calibrate
  • Hardware Config: Advanced GPIO pin configuration (if needed)

💡 LED Animations & Feedback

Color Semantics

Each LED color has a specific meaning:

  • Cyan: Origin square (selected piece)
  • White: Valid move destinations
  • Red: Capture moves or error
  • Yellow: Check warning, pawn promotion
  • Purple: En passant capture
  • Green: Move confirmation
  • Blue: Bot is thinking (AI calculations)

Animation Types

Blink

Square highlights fade in and out. Used for emphasizing valid moves and current position.

Capture

Expanding red/yellow wave rings emanate from the capture square. Celebratory and clear visual feedback.

Promotion

Yellow waterfall animation cascades down when a pawn is promoted. Indicates special event.

Firework

Celebration rings expand across the board. Triggered on checkmate or game end.

Thinking (Bot)

Corner LEDs breathe in and out with blue color. Shows the AI is calculating its move.

Waiting

White LEDs march around the board perimeter. Indicates waiting for opponent's move or input.

Flash

Full board flashes quickly. Used for errors, invalid moves, or critical alerts.

Move Highlight

When a move is made, the from/to squares are highlighted in green for confirmation.

⚙️ Board Settings & Options

LED & Display Settings

  • Brightness (0-255): Controls overall LED intensity. Higher = brighter, lower = dimmer for evening play
  • Dark Square Dimming (20-100%): Multiply on dark squares for even board lighting. Lower = more dimmed dark squares

WiFi Configuration

  • Device Name: 1-32 characters, no spaces. Used for mDNS (devicename.local) and AP network SSID
  • Scan All Channels: Enable for mesh networks, adds ~10 seconds to WiFi connection time
  • Network Selection: Choose from saved networks or scan for available networks
  • Automatic Reconnection: Device attempts to reconnect if WiFi drops

Lichess Configuration

  • API Token: Personal authentication for Lichess online play
  • Token Management: Remove or update token from settings page
  • Status Display: Shows if token is valid and connected

Game History & Management

  • Game Library: View all saved games with metadata
  • Game Limit: Up to 50 games stored on device
  • Storage Management: Oldest games automatically deleted when storage limit approached
  • Game Replay: Load any previous game and review moves
  • PGN Export: Games can be exported in PGN format for analysis

Hardware Advanced Options

  • GPIO Pin Configuration: Customize which GPIO pins control LEDs, sensors, and shift register
  • Sensor Calibration: Map physical sensor positions to logical board coordinates
  • Board Calibration Tool: Interactive setup wizard for new hardware or troubleshooting

OTA Updates

  • Automatic Update Check: Device periodically checks GitHub for new firmware versions
  • Auto-Update Toggle: Enable or disable automatic firmware updates
  • Manual Upload: Upload firmware or web assets directly via web interface
